# CruiseOps Antigua

## Deploy

1. Delete the old repository contents.
2. Upload the contents of this package to the repository root.
3. Confirm the homepage is named exactly `index.html` (lowercase).
4. Commit to the `main` branch.
5. In Settings → Pages, choose **GitHub Actions**.
6. In Actions, run **Deploy CruiseOps Antigua to GitHub Pages**.

Do not upload the outer package folder itself; upload its contents.
